# LifeOS — Kapital и Ritmo

Два приложения на общем ядре. Открываются на телефоне как обычные
приложения (иконка на экране «Домой»), работают без интернета,
данные хранятся на самом устройстве.

| | |
|---|---|
| **Kapital** | Финансы. Личные и по компании — раздельно. Счета в песо и долларах, расходы/доходы/переводы, категории, регулярные платежи, отчёты и выгрузка в Excel. |
| **Ritmo** | Дисциплина. Привычки по четырём областям (тело, разум, здоровье, работа), отметки по дням, серии, календарь прогресса, заметка и самочувствие дня. |

## Как поставить на телефон

1. Открыть адрес приложения в браузере телефона.
2. **iPhone (Safari):** кнопка «Поделиться» внизу → «На экран «Домой».
3. **Android (Chrome):** меню «⋮» → «Установить приложение».

После установки приложение запускается с иконки и работает без сети.

## Где лежат данные

Только в памяти браузера на этом устройстве. Ни на какой сервер они не уходят.
Отсюда два следствия:

- данные не синхронизируются между телефоном и компьютером;
- если стереть данные браузера или сменить телефон — они пропадут.

Поэтому в разделе «Ещё» есть **резервная копия**: раз в месяц выгружайте файл
и храните его в облаке. Тот же файл восстанавливает всё обратно.

## Разработка

```bash
npm run dev      # локальный сервер, адрес для телефона по Wi-Fi выводится в консоль
npm run check    # автопроверка в настоящем браузере: ошибки, вёрстка, сценарии ввода
npm run icons    # перерисовать иконки приложений
npm run build    # собрать docs/ для публикации
```

Публикация: `npm run build`, затем коммит и push — GitHub Pages отдаёт папку `docs/`.

### Как устроено

```
shared/          общее ядро обоих приложений
  css/base.css     дизайн-система: цвета, карточки, кнопки, листы
  js/store.js      хранилище: запись на устройство, копии, миграции
  js/i18n.js       переводы (ru / es / en)
  js/ui.js         элементы интерфейса
  js/format.js     деньги и даты
  js/pwa.js        установка на телефон, тема, уведомления
  js/shell.js      каркас: шапка, экраны, нижние вкладки
apps/kapital/    финансы
apps/ritmo/      привычки
tools/           сборка, иконки, автопроверка
```

Приложения написаны на обычном HTML/CSS/JavaScript без сборщиков и фреймворков:
любой файл можно открыть и прочитать, ничего не «скомпилировано».

Суммы денег хранятся в целых центах — иначе копейки со временем расходятся
из-за особенностей дробных чисел.

`apps/*/shared` — символическая ссылка на общее ядро. При сборке она
заменяется настоящими файлами: офлайн-кэш не умеет обслуживать файлы
выше своей папки.

### Что дальше, если делать из этого продукт по подписке

Заложено, но пока не включено:

1. **Облако вместо устройства.** `shared/js/store.js` — единственное место,
   где данные пишутся и читаются. Подключение Supabase меняет только его.
2. **Вход по аккаунту.** Нужен, чтобы данные жили на нескольких устройствах.
3. **Подписка.** Stripe или Mercado Pago (для Мексики) + проверка статуса.
4. **Испанский интерфейс.** Словарь уже есть целиком — включается
   переключателем в настройках.
